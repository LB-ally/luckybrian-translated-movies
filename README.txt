LUCKYBRIAN TRANSLATED MOVIES — STARTER WEBSITE
================================================

WHAT THIS IS
A responsive, interactive frontend prototype inspired by common movie-catalogue patterns.
It is an independent project and is not affiliated with Byadala.

FEATURES
- Responsive dark-theme homepage and movie catalogue
- Search by title, genre, year, and narrator
- Genre filters
- Movie details modal
- Save-to-list hearts (stored in this browser)
- Local catalogue manager to add movie entries
- Optional poster and authorized video URL fields
- Optional browser video player and download link when a video URL is provided
- Export catalogue to JSON
- No payment gateway, subscriptions, or paid downloads

IMPORTANT LIMITATIONS
- This is a frontend prototype, not yet a production website.
- Catalogue additions are stored in the current browser only; they do not upload to a server.
- No secure admin login, database, server API, user accounts, or cloud video storage is included.
- Demo movie titles are fictional examples. No movie files are bundled.
- Only upload, link, or distribute films, translations, posters, and audio that you own or have permission to distribute.
- A third-party video host must allow playback/embedding; download links may behave differently depending on the host.

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Search, filter, open movie cards, and try “Add a movie”.
4. To publish online, upload index.html to a static hosting provider such as GitHub Pages, Cloudflare Pages, or Netlify.
   Hosting-provider terms and limits apply. Do not put secret API keys or private files in this frontend.

NEXT STEPS TO MAKE IT A REAL PUBLIC PLATFORM
1. Create a GitHub repository and deploy the frontend.
2. Add a backend and database (for example, Supabase/PostgreSQL).
3. Add a secure admin login and server-side movie management.
4. Add lawful video storage and short-lived signed download links.
5. Add TMDB metadata only after checking its API terms, attribution, and image requirements.
6. Add privacy/terms pages and test on mobile networks.
